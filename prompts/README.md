# Prompt Writeups

This folder contains one file per artifact entry in the main [README](../README.md), following [TEMPLATE.md](../TEMPLATE.md).

Each writeup includes the actual prompt used, any refinement steps, and — most importantly — an explanation of *why* the prompt worked. The goal is to teach prompting patterns, not just hand out a copy-paste prompt.

Browse by category in the main list, or just scroll the files here alphabetically.
